# HTML presentations

Static HTML slides with a fixed 16:9 stage, themes, navigation and reading notes. Open an actual talk's HTML or presenter in a modern browser; no build step is needed. Fonts and icons may use public CDNs with system fallbacks.

- [Workflow](PRESENTATION-WORKFLOW.md): create, revise, check and export a talk.
- [File guide](FILE-GUIDE.md): where each kind of content belongs.
- [AI project rules](AGENTS.md) and [slide skill](.agents/skills/presentation-slides/SKILL.md).
- [Complete slide-guide requirements](config/slide-guide-spec.md).
- [Portable starter](starter/presentation-starter.txt) for an AI chat without repository access.
- [Working layout examples](.agents/skills/presentation-slides/resources/slide-type-examples.html).

`my-first-talk` is a conceptual example name only; that folder is not supplied. Create a folder named for your real talk.

Live shared colour values are in `assets/palettes.css`. Reusable non-colour presets are in `config/slide-presets.md`.
