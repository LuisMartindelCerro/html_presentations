# HTML presentations

For presentation work, read `.agents/skills/presentation-slides/SKILL.md` for workflow and reference routing.

- Identify the actual talk from the user or active files; do not assume a sample folder exists.
- Preserve unrelated changes. Do not automatically commit, push, publish, change remotes or install system software.
- Use supplied facts and accessible sources; do not invent facts or quotes.
- Every slide content or behaviour change must include the complete matching `slide-guide.md` entry, following `config/slide-guide-spec.md`.
